# 🎵 Tackify

Tackify is a beginner-friendly music playlist website created using only HTML.  
The project contains different music genres and playlist pages where users can explore songs by mood and category.

---

## 🌟 Features

- 🎶 Multiple music genres
- 💖 Romantic Hindi playlist
- 🔥 Party Vibe Mix
- 🎧 English songs section
- 💔 Sad songs playlist
- 🎤 Rap songs playlist
- 🖼️ images
- 🔗 Song play buttons with links
- 📱 Mobile-friendly viewport support
- 🌑 Dark-themed interface using HTML only
